# WDI-Data

# World Development Indicators (WDI) Data

This repository contains a manually selected dataset from the **World Development Indicators (WDI)** provided by the **World Bank Group**.  
The dataset (`WDI_csv.zip`) has been pre-filtered based on specific country and indicator selections.
